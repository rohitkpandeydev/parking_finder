# Smart Parking Project Context
**Goal:** A real-time parking finder app with reservations, payments, and alerts.

## Tech Stack
- **Frontend:** React (Vite recommended)
- **Backend:** Node.js with TypeScript (Express/NestJS)
- **Database:** PostgreSQL (RDS connected to EC2)
- **Infrastructure:** AWS EC2 (Public IP available), RDS
- **Maps:** Google Maps API / Mapbox (Integration required)

## Coding Standards
- Use functional components with Hooks for React.
- Strict typing for TypeScript interfaces.
- API endpoints should follow RESTful conventions.
- Styling: CSS Modules or Tailwind CSS (specify your preference).

## Core Features to Implement
1. Spot listing module
2. Reservation workflow
3. User dashboard
4. Maps integration
5. Alert system for availability
6. Payment module
7. Notifications
8. Testing workflows
